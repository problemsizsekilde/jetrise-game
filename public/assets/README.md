# Lucky Jet — Xüsusi PNG Qrafik Elementlər

Bu qovluğa öz xüsusi PNG fayllarınızı əlavə edərək `src/config/assets.ts` faylından aktivləşdirə bilərsiniz:

- `character.png` — Uçan personaj (şəffaf arxa planlı PNG, tövsiyə edilən ölçü: 256x256)
- `stage-bg.png` — Uçuş səhnəsinin xüsusi arxa plan şəkli
- `card-frame.png` — Mərc kartı və ya əmsal çərçivəsi üçün overlay PNG
- `logo.png` — Başlıq loqosu

Faylları bura yerləşdirib `src/config/assets.ts` daxilində müvafiq yolu aktiv etmək kifayətdir; fayl tapılmazsa sistem avtomatik olaraq daxili vektor/canvas qrafikasından istifadə edir.
